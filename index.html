        Your goals are stored in a JSON file inside your own private GitHub repo. Create a fine-grained token with access to that repo only and the Contents: Read and write permission. The token is stored only in this browser; this site has no server and only talks to api.github.com. If the file doesn't exist, the app offers to create it. Tasks, areas and habits live next to it (tasks.json, domains.json, habits.json).
